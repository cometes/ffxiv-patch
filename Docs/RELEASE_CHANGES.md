### 대사 플레이어 호칭을 글로벌 원문처럼 복원

- 한국어 대사에서 플레이어를 항상 풀네임(`이름 성`)으로 부르던 표시를 개선했습니다. 글로벌 일본어 원문처럼 상황에 따라 이름 또는 성으로 부릅니다.
- 별도 선택 옵션 없이, 텍스트 패치를 생성할 때 자동으로 적용됩니다.
- 영어 베이스에서도 일본어 원문의 호칭을 기준으로 적용합니다.
- 한국어 조사도 실제 표시되는 이름·성을 기준으로 선택하도록 처리했습니다.
- 조건 분기나 이름 참조 수 차이 때문에 안전하게 대응할 수 없거나, 매크로가 잘못된 문자열은 한국어 원문을 유지합니다.

**예시** — 캐릭터 이름이 `Yuna Kim`인 경우
- 기존: “어머, Yuna Kim……앗, 그게 아니라, Yuna Kim 님 아니십니까!”
- 변경: “어머, Yuna……앗, 그게 아니라, Kim 님 아니십니까!”

**적용 안내**
- 기존 패치가 적용되어 있다면 먼저 제거한 뒤, 새 실행 파일로 **텍스트가 포함된 패치를 다시 생성·적용**해 주세요.
- 이미 생성·적용한 패치에는 자동으로 반영되지 않습니다. 폰트 전용 패치만 적용해도 호칭은 바뀌지 않습니다.

**확인 상태**
- 이름·성 대응, 조사, 중첩 분기, 잘못된 매크로 입력을 포함한 회귀 테스트 21개를 통과했습니다.
- 단일 실행 파일의 제너레이터·폰트 패키지·RSV 맵 내장과 추출, 합성 EXD의 텍스트 재작성 경로를 확인했습니다.
- 이번 빌드의 게임 내 최종 표시는 추가 확인이 필요합니다.
