### 검증 범위와 알려진 제한

- 검증기에서 잘못 통과하던 13건의 실패 판정, 정상 Story/부분 폴백, JA/EN Full 기준선 일치와 케프카 상용구·후속 행을 확인했습니다. UI 혼입, 해시 변조와 잘못된 후속 대사는 거부합니다.

- Subrows 시트는 미지원입니다. 버전 일치와 clean/original index 확보 조건을 유지하며, 이번 작업으로 로비/인게임 폰트 알고리즘을 광범위하게 변경하지 않았습니다.
