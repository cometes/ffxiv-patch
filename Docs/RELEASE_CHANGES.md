### 마수조련사 UI 표시 개선 및 소지품 간격 조정

- 마수조련사 시련의 등급·효과 유형·대상·속성 번역 누락을 수정했습니다.
- 마수 랭크의 발바닥 아이콘을 복원했습니다.
- 마수도감 제목과 랭크업 한글의 크기·세로 정렬을 개선했습니다.
- 랭크업 문구의 `업`과 느낌표 사이 간격을 넓혔습니다.
- 소지품의 일본어 부제를 유지하면서, 기본·대형·확장 소지품 창의 부제 간격을 조정했습니다.
- 캐릭터 선택창에서 직업 부제가 한글 직업명과 중복되던 문제를 수정했습니다.

**확인 상태**
- 마수도감 제목과 랭크업의 크기·잘림 개선은 실제 게임 화면에서 확인했습니다.
- 이번 소지품 부제 위치와 느낌표 간격 변경은 생성 데이터·오프라인 검증을 완료했으며, 게임 내 최종 표시는 추가 확인이 필요합니다.

**적용 안내**
새 버전으로 **일반 폰트 포함 패치를 다시 생성·적용**해 주세요. 기존에 생성한 패치에는 이번 수정이 반영되지 않습니다.
